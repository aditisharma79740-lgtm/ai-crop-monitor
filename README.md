# 🌱AI crop monitor

An AI-powered crop monitoring and irrigation advisory system using satellite imagery.

#  Project Goal

Develop a prototype that can:

- Identify crop health using satellite imagery
- Detect moisture
- stress level
- Recommend irrigation accordingly
- Visualize results through an interactive dashboard

 # Technologies

- Python
- Google Earth Engine
- Streamlit
- Scikit-learn
- Sentinel-2
